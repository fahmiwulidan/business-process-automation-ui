# Injani Flow - Enterprise BPA & Controls Governance

Frontend prototype for an enterprise Business Process Automation (BPA) and Continuous Controls Governance platform.

## About

This project was created as a frontend prototype for a UI/UX design challenge at PT. INJANI SYSTEMS.

The interface focuses on workflow management, approval processes, controls governance, automation schedules, SLA analytics, and audit history.

## Features

- Personalized End-User Dashboard
- Pending Approvals
- Workflow Catalog
- My Requests
- Controls Registry
- Automation Schedules
- SLA Reports & Analytics
- Approval History & Audit Trail
- Batch Approval
- Dashboard Customization
- Approval Review Drawer

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- Dummy Data

## Note

This project is a frontend prototype using dummy data and is not connected to a production backend or database.

## Project Purpose

UI/UX and frontend prototype created for a recruitment design challenge.
